# Memory Game

Игра на поиск пар. На поле 16 карточек: 8 планет, каждая встречается дважды. Нужно открывать карточки по две и найти все пары за наименьшее число ходов.

## Как играть

Игра начинается сразу при открытии страницы. Все карточки лежат рубашкой вверх, счётчик ходов равен 0, найденных пар — 0 из 8.

1. Откройте первую карточку, затем вторую. Это один ход.
2. Если планеты совпали, карточки остаются открытыми.
3. Если планеты разные, они закрываются примерно через секунду. Пока пара открыта, другие карточки выбрать нельзя.
4. Когда найдены все 8 пар, открывается окно победы с числом ходов.

В шапке есть две кнопки:

- **Новая игра** — спрашивает подтверждение и начинает партию заново: карточки перемешиваются, счётчики обнуляются.
- **Таблица лидеров** — показывает до 10 лучших результатов. Для каждой игры указаны место, число ходов и дата. Меньше ходов — выше место. При равенстве выше более ранняя игра. Если результатов нет, показывается сообщение «Пока нет результатов».

Завершённые игры сохраняются в `localStorage` и остаются после перезагрузки страницы. Незаконченная партия в таблицу не попадает.

## Локальный запуск

Нужен только браузер и любой локальный сервер. Открывать `index.html` двойным щелчком не стоит: приложение собрано из ES-модулей, и браузер их не загрузит как файл с диска.

Из корня проекта:

```bash
python3 -m http.server 5500
```

Затем откройте в браузере [http://127.0.0.1:5500](http://127.0.0.1:5500).

Сервер останавливается сочетанием клавиш `Ctrl+C` в том же терминале.
